# Binyamina-Givat Ada Budget Explorer / מגלים את תקציב בנימינה-גבעת עדה

An interactive bilingual (Hebrew/English) explorer of the Binyamina-Givat Ada local council's regular budget, 2020-2026.

אתר אינטראקטיבי דו-לשוני (עברית/English) להבנת התקציב הרגיל של מועצת בנימינה-גבעת עדה, 2020-2026.

- Live site: https://goidelg.github.io/binyamina-budget/
- Data: 19 official budget documents published on the council website (bin-ada.co.il), linked from the site's document library.
- Independent, unofficial project. Not a council website. Figures are nominal, in thousand NIS as published; plans vs. actuals are labeled per stage.
